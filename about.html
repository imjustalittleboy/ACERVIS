About the Protocol

The ACERVIS Initiative

ACERVIS is a Pan-Nigerian blockchain-based academic credential verification protocol. It was conceived to solve the endemic problem of certificate forgery, bureaucratic verification delays, and the lack of a unified national infrastructure for academic trust.

By anchoring cryptographic hashes of credentials to the Polygon Amoy blockchain, the protocol provides mathematical certainty of authenticity — forgery becomes computationally impossible, verification becomes instantaneous, and the need for centralized trust is eliminated.

Architecture

The protocol operates on five layers: a user-facing frontend (Public Portal & Admin Center), a Vercel Edge serverless API layer, a cryptographic synthesis engine using HMAC-SHA256, a Neon Postgres database for metadata storage, and the Polygon L2 blockchain as the immutable anchor of truth.

// Hybrid Security
Metadata lives in the database; proof lives on the blockchain. Neither alone is sufficient to forge a credential.
// Separation of Powers
Super Admins govern institutions; institutions issue credentials. No single entity controls the full pipeline.
// Future-Proof
Multi-hash architecture supports migration to SHA-3, BLAKE3, or post-quantum algorithms.
// National Scale
Built on serverless infrastructure designed to handle Nigeria's 2M+ annual graduates.
